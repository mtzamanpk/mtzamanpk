### 🚀 Featured Projects

Some of my most substantial projects, spanning community tools, transportation, business automation, and game development.

#### VX Converter — Better Link Sharing on Discord

Built a Discord bot serving **over 3,000 users** that converts social media links into versions that support rich previews, removing the need to edit links manually. Recent improvements add provider validation, fallbacks, and caching while preserving original messages when conversion fails.

**Tools:** Discord API · Next.js · Tailwind CSS · Railway · Vercel

[Website & Add to Discord](https://vx-converter.vercel.app/) · [Landing Page Source](https://github.com/mtzamanpk/vx-converter-web)

#### Fleet — Ride-Sharing Capstone

Co-developed a ride-sharing platform where drivers set their own prices, with a **5% platform fee model**. Built web and mobile frontends backed by a shared API, taking the team project through prototypes, successive MVPs, documentation, and a final demo.

**Stack:** React · React Native · Expo · Node.js · Express · MongoDB

[Source & Project Documentation](https://github.com/mtzamanpk/Fleet)

#### ZamanCore — Creator & Brand Outreach Automation

Built Python automation for a PC-hardware influencer agency, connecting creator discovery, contact enrichment, personalized outreach drafts, reply classification, and CRM reporting. Integrates Google Sheets, YouTube, Gmail, and LLM APIs to support the workflow from lead discovery to deal tracking, with human review before sending.

**Tools:** Python · Google Sheets API · YouTube API · Gmail API · LLM APIs

*Private repository.*

#### EnviroFormer — Godot Game Project

Developed a Godot 4 game with a downloadable Windows release, source code, and documented Scrum milestones. A substantial game-development project covering implementation, release packaging, and team planning.
